## 🚀 Featured Projects

### 01. MedAssist AI — Medical Knowledge Assistant

**Tech Stack**

`Python` `LangChain` `Hugging Face`
`Pinecone` `RAG` `Embeddings`

A retrieval-augmented medical knowledge assistant designed to retrieve relevant information from a document-based knowledge base.

**Key work**

- Processed medical PDF documents for knowledge retrieval.
- Split documents into smaller chunks.
- Generated embeddings for semantic search.
- Stored and retrieved vectors using Pinecone.
- Used retrieved context to generate grounded responses.
